# Trend To Content Map

| 熱點類型 | 可轉換方向 | 注意事項 |
| --- | --- | --- |
| 熱門 AI 工具 | 短影片 / 模板商品 / 自動化教學 | 需要確認工具是否真的可用，不誇大效果。 |
| 熱門迷因 | LINE 貼圖 / 短影片 | 避免直接複製梗圖或侵犯角色版權。 |
| 熱門動畫風格 | AI 動畫企劃 | 不模仿特定受保護作品到混淆程度。 |
| 熱門幣種 | crypto 風險報告 | 不承諾收益，不提供自動下單。 |
| 熱門求職 / WHV 問題 | 模板商品 / 短影音 | 優先做實用清單、履歷、面試腳本。 |

## 判斷順序

1. 先判斷熱點來源與熱度原因。
2. 再判斷適合哪個部門。
3. 再評估 7 天內是否能做 MVP。
4. 最後交給 idea-evaluator 決定優先級。
