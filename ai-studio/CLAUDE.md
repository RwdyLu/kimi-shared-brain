# Rudy Claude Code Studio Rules

## 使用者

使用者是 Rudy，目前想建立一套 AI 自動化公司工作台，用來管理內容頻道、AI 動畫、LINE 貼圖、加密貨幣項目、數位模板商品與未來突發奇想的商業實驗。

## 語言規則

* 永遠用繁體中文回覆 Rudy。
* 不要使用簡體中文。
* 技術名詞可以保留英文，但要用白話解釋。
* 回答要偏實作、步驟、風險、下一步。
* 不要用空泛的行銷語氣。

## 工作規則

* 任務要先規劃再執行。
* 複雜任務要先列出 plan。
* 一個任務一個對話。
* 任務完成後輸出總結。
* 不確定時要標註不確定，不要假裝知道。
* 不要假裝完成沒有做的事情。

## GitHub 規則

* 所有 code 和文件都應該透過 GitHub 版本控管。
* 不要直接改 main branch。
* 修改前建立 branch。
* 修改後 commit。
* 重要修改要開 Pull Request。
* 每次修改要說明改了哪些檔案、為什麼改、有什麼風險、下一步是什麼。

## 安全規則

* 不可以刪除檔案。
* 不可以清空資料夾。
* 不可以修改 .env、API key、金流、交易、部署設定。
* 不可以自動發 Email。
* 不可以自動發布社群貼文。
* 不可以自動上傳 YouTube / TikTok / Shorts。
* 不可以自動下單交易。
* 不可以自動部署正式網站。
* 所有高風險操作都必須先問 Rudy。
* 高風險操作包含：刪檔、發文、發信、上傳影片、部署網站、交易、修改 API key、修改金流、修改資料庫、修改權限設定。

## 資料夾規則

* AI 產出放 outputs/
* 報告放 reports/
* 草稿放 drafts/
* 商品放 products/
* 素材放 assets/
* 歷史資料放 archive/
* 不要把輸出檔案亂放在根目錄。

## 點子規則

* 所有新點子都必須先經過 workflows/evaluate-new-idea.md
* 所有熱門話題都必須先經過 trend-scout 和 trend-to-idea
* 不可以直接追熱點亂做。
* 熱點只能當素材，不等於一定值得做。
* 每週必須回顧哪些項目要保留、暫停、砍掉。
