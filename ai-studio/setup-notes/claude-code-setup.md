# Claude Code Setup

這個資料夾是 Claude Code 的主要工作區。使用前應先讀 ai-studio/CLAUDE.md，確認語言、安全、GitHub 與資料夾規則。

## 建議模式

* 建議使用 Plan mode 或 Ask mode。
* 不建議一開始使用 bypass permissions。
* 一個任務一個 session。
* 複雜任務先要求 Claude Code 列 plan。
* 任務完成後寫入 reports/ 或 outputs/。

## 初期限制

第一階段只做文件、研究、草稿、流程設計與安全審查，不接 API、不建立排程、不自動發布、不自動交易。
